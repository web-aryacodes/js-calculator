# 🧮 JS Calculator

A modern calculator built using HTML, CSS, and JavaScript with advanced UI and features.

---

## ✨ Features

- Basic arithmetic operations (+, −, ×, ÷)
- Delete last input (DEL)
- Clear display (C)
- Percentage (%), Square (x²), Square Root (√)
- Calculation history with auto-scroll
- Clear history option
- Keyboard support
- Dark / Light theme toggle 🌙☀️
- Responsive and clean UI

---

## 🎨 UI Highlights

- Modern button layout
- Sidebar history panel
- Dark mode with custom styling
- Smooth hover and click animations
- Custom scrollbar in dark theme

---

## 🛠 Technologies Used

- HTML5
- CSS
- JavaScript

---

## 🚀 How to Run

1. Download or clone the repository  
2. Open `index.html` in your browser
